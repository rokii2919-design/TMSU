# TMSU — The Myriad Sea Universe

Repository for the story bible, episode writing, manhwa production rules, scripts, and webtoon layout prototypes for **มหาสมุทรหมื่นภพ — The Myriad Sea Universe**.

## Current Status

The creative project is paused for a production reset. The latest working rule is: do not generate a full episode immediately. First create:

1. Character model sheets for main, supporting, and recurring characters
2. Prop sheets for key weapons and accessories
3. A color script for each episode/scene
4. Thumbnail layouts with speech-balloon placement
5. QA rules for anatomy, continuity, tone, lettering, and action flow
