# The Myriad Sea Universe (TMSU)

An original fantasy multiverse project created by Golf.

## Core Systems
- SCVB (Seedance-style Cinematic Video Builder)
- SCVB-M (Manhwa/Webtoon Mode)
- VESB (Visual Engineering Skill Builder)
- K_AI (Character & Narrative Memory System)

## Universe
The Myriad Sea is an interdimensional ocean between realities.

### World Types
- Complete Worlds
- World Fragments
- Dream Worlds
- Forbidden Worlds
- Erased Worlds

## Main Characters
### Ray (เรย์)
A nameless traveler whose true name cannot be read by the universe.

### Park Arin
A world hunter wielding the Moonbell Sword.
