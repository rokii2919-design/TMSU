# The Myriad Sea Universe — Manhwa Production Bible

เอกสารนี้คือกฎผลิตภาพและหน้าการ์ตูนของโปรเจ็ก `มหาสมุทรหมื่นภพ` ตั้งแต่ตอนถัดไปเป็นต้นไป ใช้เพื่อแก้ปัญหาที่เจอใน V3, V4 และ V5 ได้แก่ คาแร็กเตอร์ไม่ต่อเนื่อง, โทนสีแกว่ง, ซีนตกจากฟ้าร่างบิด, ซีนเรียกดาบผิดเพี้ยน, การต่อสู้กระโดด และการลงคำที่แยกจากตัวละครมากเกินไป

## 1. บทบาทการทำงาน

จากนี้ต้องทำงานแบบทีมมังฮวาจริง ไม่ใช่ทำภาพสวยแยกชิ้น:

1. นักเขียน: คุมจังหวะเรื่อง มุก บทพูด และความต่อเนื่องของอารมณ์
2. สตอรี่บอร์ด: แตกช็อตให้คนอ่านตามทัน โดยหนึ่งช็อตมีหน้าที่ชัดเจน
3. Character Designer: ล็อกหน้าตา เสื้อผ้า ทรงผม อาวุธ เครื่องประดับ และสัดส่วน
4. Art Director: คุมลายเส้น โทนสี แสง เงา และระดับรายละเอียดให้เป็นภาษาเดียวกันทั้งตอน
5. Letterer: วางคำในภาพ ใกล้ตัวละครที่พูด อ่านง่าย แต่ไม่บังหน้า มือ อาวุธ หรือจุดแอ็กชัน
6. QA: ตรวจ anatomy, continuity, balloon placement, color consistency ก่อนส่งงาน

## 2. Diagnosis จากงานเดิม

### ปัญหา A: คาแร็กเตอร์ไม่ต่อเนื่อง

สาเหตุ:
- ใช้พรอมป์ตัวละครซ้ำ แต่ไม่มี model sheet ที่บังคับสัดส่วน หน้าตา ทรงผม และเสื้อผ้า
- ไม่มี expression sheet ทำให้ใบหน้าแต่ละช็อตเปลี่ยนไป
- ไม่มี prop sheet สำหรับ Noctis Null, Selenia, นาฬิกาเรย์, ระฆังจันทร์ และชุดลูเมีย

กฎแก้:
- ต้องทำ character turnaround ก่อนผลิตตอนจริง
- แต่ละตัวต้องมี front, 3/4, side, back, head close-up, hand detail, outfit detail, accessory detail
- ทุกตัวต้องมี expression sheet อย่างน้อย 8 สีหน้า
- ทุก prop สำคัญต้องมีภาพ reference แยก

### ปัญหา B: โทนสีไม่สม่ำเสมอ

สาเหตุ:
- แต่ละภาพตีความแสงและ saturation ใหม่เอง
- ไม่มี color script รายตอน
- ฉากตลาดบางภาพสดเกิน บางภาพหม่นเกิน ทำให้อ่านเหมือนคนละเรื่อง

กฎแก้:
- หนึ่งตอนต้องมี color script ก่อนผลิตภาพ
- ทุกช็อตในฉากเดียวกันต้องใช้ mood เดียวกัน เว้นแต่มีเหตุการณ์เปลี่ยนสภาวะชัดเจน เช่น รอยแยกเปิด หรือเงาผู้ไร้โลกบุก
- ห้ามเปลี่ยน saturation/contrast แบบสุ่มระหว่างช็อต

### ปัญหา C: ซีนตกจากฟ้าร่างบิดหรือขาเกิน

สาเหตุ:
- มุมกล้องซับซ้อนเกินไป
- พยายามให้หนึ่งภาพเล่าทั้งการตกและการปะทะ
- ใช้ full-body action pose ในฉากที่เสี่ยง anatomy สูง

กฎแก้:
- แยกซีนตกจากฟ้าเป็นช็อตย่อย ไม่ใช้ภาพเดียวจบ
- ใช้ close-up หรือ crop เพื่อคุม anatomy เช่น มือหลุดจากรอยแยก, รองเท้าแตะกันสาด, ไหล่ชนลัง
- ถ้าต้องเห็นทั้งตัว ให้ใช้ pose ง่าย อ่าน silhouette ชัด และระบุ `one body, two arms, two legs` ทุกครั้ง
- ห้ามใช้มุมกล้องที่ทำให้แขนขาซ้อนกันจนอ่านไม่ออก

### ปัญหา D: ซีนเรียกดาบผิดเพี้ยน

สาเหตุ:
- ไม่มี prop breakdown ของ Noctis Null
- ให้ดาบโผล่ในภาพเดียว ทำให้ระบบภาพเดาเอง

กฎแก้:
- ซีนเรียกดาบต้องเป็นลำดับ 5 ช็อต:
  1. นาฬิกาดำที่ข้อมือซ้ายเริ่มแตกแสงสุญญะ
  2. เส้นสุญญะพันฝ่ามือ
  3. ด้ามดาบก่อรูปก่อน
  4. ใบดาบดำด้านกางออกเหมือนรอยตัดมิติ
  5. เรย์ตั้งท่าพร้อมสู้
- ห้ามให้ดาบมีรายละเอียดแฟนตาซีเกิน เช่น ใบดาบทอง ไฟสีแดง หรือทรงดาบคนละแบบ

### ปัญหา E: การต่อสู้กระโดด

สาเหตุ:
- ข้ามจากเห็นศัตรูไปฟันทันที
- ขาด reaction shot และ anticipation

กฎแก้:
- แอ็กชันหนึ่งชุดต้องมีลำดับ:
  1. Threat: เห็นอันตราย
  2. Decision: ตัวละครตัดสินใจ
  3. Preparation: เตรียมท่าหรือเรียกพลัง
  4. Movement: เคลื่อนที่
  5. Contact: ปะทะ
  6. Result: ผลลัพธ์
  7. Consequence: ผลข้างเคียง

### ปัญหา F: บทพูดอยู่ในพื้นที่ขาวมากเกินไป

สาเหตุ:
- วางคำหลังภาพเสร็จ ไม่ได้วางตำแหน่งบอลลูนตั้งแต่ thumbnail
- กลัวบังภาพจนแยกบทพูดออกจากตัวละคร

กฎแก้:
- ต้องวางบอลลูนตั้งแต่ thumbnail ก่อนสร้างภาพ
- ภาพแต่ละช็อตต้องเผื่อ negative space ในภาพไว้ให้บอลลูน
- บอลลูนต้องอยู่ใกล้ตัวละครที่พูด มีหางชี้ไปที่ปาก/ใบหน้า
- ใช้พื้นที่ขาวระหว่างภาพสำหรับพักจังหวะ, narration, title card, หรือ silence เท่านั้น ไม่ใช้แทนบทพูดหลักทั้งฉาก

## 3. Visual Style Lock

### ลายเส้น

- Korean manhwa cinematic แต่ยังเป็นงานวาด ไม่ใช่ภาพประกอบ hyper-render
- เส้นคม สะอาด น้ำหนักเส้นชัด
- ใบหน้าต้องอ่านง่ายกว่ารายละเอียดเสื้อผ้า
- ลด texture ที่ละเอียดเกิน เพราะอ่านยาวแล้วตาลาย
- ฉากหลังใช้รายละเอียดเฉพาะจุดที่ช่วยเล่าเรื่อง ไม่ถมทั้งภาพ

### แสงและสี

Palette หลักของตอน 1:

- ตลาดเจ็ดลมปกติ: ฟ้าทอง, ครีมเมฆ, น้ำเงินอ่อน, ทองเหลือง
- รอยแยกสุญญะ: ม่วงดำ, น้ำเงินเข้ม, แสง rim violet
- อาริน/ระฆังจันทร์: ขาวเงิน, น้ำเงินเข้ม, ฟ้าเย็น
- เงาผู้ไร้โลก: ดำม่วง, รอยแตกม่วง, desaturated background
- Noctis Null: ดำด้าน ไม่มีคมชัด เหมือนช่องว่างรูปดาบ

กฎ saturation:
- ช่วงตลาดคอมเมดี้: saturation กลางถึงสด แต่ไม่จัด
- ช่วงรอยแยก: ลดความอบอุ่นของแสง เพิ่มม่วงดำ
- ช่วงเงาผู้ไร้โลก: ลดสีฉากหลัง ให้ตัวละครและพลังอ่านชัด
- ห้ามสลับสด/หม่นโดยไม่มีเหตุผลทางเรื่อง

## 4. Character Lock

### เรย์

- อายุภาพ: ชายหนุ่ม 20 ต้น ๆ
- เชื้อชาติภาพ: เอเชีย/ไทย
- ผม: ดำ messy undercut, ปอยผมหน้าผากชัด, ห้ามเปลี่ยนเป็นผมยาวหรือผมตั้ง
- แว่น: กลมบาง กรอบดำ/เงิน ต้องมีทุกช็อตยกเว้นหลุดจากแรงกระแทกชั่วคราว
- เสื้อ: ดำ futuristic tactical streetwear, collar สูง, ซิป, สายรัด, texture น้อยแต่ silhouette ชัด
- ข้อมือซ้าย: นาฬิกาดำ ต้องเห็นในช็อตพลัง
- สีหน้า: หน้าตาย กวนเงียบ สุขุม
- ห้าม: ยิ้มหวานเกิน, ทำหน้าเด็กเกิน, ชุดกลายเป็นสูท/เกราะแฟนตาซีเต็มตัว

### อาริน

- ผม: เงินขาวยาว ลื่นและสะอาด ทรงเดิม
- ชุด: เสื้อคลุมนักล่าสีขาวเงิน + น้ำเงินเข้ม
- อาวุธ: ดาบ Selenia สีเงิน มีระฆังจันทร์เล็กติดปลายด้าม
- สีหน้า: จริงจัง สุขุม มีความกังวลเล็ก ๆ เมื่อพลังเรย์ผิดปกติ
- ห้าม: ผมกลายเป็นม่วง/ฟ้า, ชุดกลายเป็นเกราะทอง, ดาบไม่มีระฆัง

### ลูเมีย

- ผม: บ็อบน้ำตาลเกาลัด
- เครื่องประดับ: แว่นช่างทองเหลืองบนหัว
- ชุด: เสื้อฟ้าอ่อน + เอี๊ยม/ผ้ากันเปื้อนครีมน้ำตาล
- Props: ถาด, ที่คีบ, ประแจ, ขนมเมฆา
- สีหน้า: ตลก โวยวาย สด มีชีวิต
- ห้าม: ดูเป็นสาวนักดาบ, ชุดกลายเป็น maid/fantasy princess, สีผมเปลี่ยน

### ตัวละครเสริมและตัวละครใหม่

- ตัวละครเสริมที่มีบทพูด, มีฉากต่อสู้, หรือจะกลับมาอีกในตอนหลัง ต้องมี character model sheet ก่อนใช้งานจริง
- ตัวละครใหม่ทุกตัวที่เปิดตัวหลังจากนี้ต้องมีอย่างน้อย: front view, 3/4 view, head close-up, outfit detail, color swatches และ expression หลัก
- ตัวละครประกอบที่โผล่ครั้งเดียวแบบไม่มีบทพูดอาจใช้ crowd design ได้ แต่ถ้ามีชื่อหรือมีบทบาทต่อเนื่อง ต้องยกระดับเป็น model sheet
- ฝ่าย/องค์กรเดียวกันต้องมี visual language ร่วมกัน เช่น โทนสี เครื่องหมาย ชุด อาวุธ และ silhouette เพื่อให้คนอ่านจำกลุ่มได้ทันที
- ห้ามออกแบบตัวละครใหม่แบบช็อตต่อช็อต เพราะจะทำให้เนื้อเรื่องและภาพขาดความลื่นไหล

## 5. Lettering และการลงคำ

ฟอนต์หลัก:
- Kanit

กฎบอลลูน:
- บทพูดหลักอยู่ในภาพ
- ไม่เกิน 3 บอลลูนต่อหนึ่งช็อต
- หนึ่งบอลลูนควรมี 1 ประโยค หรือ 1 จังหวะพูด
- ถ้าบทพูดยาว ให้แตกเป็นหลายบอลลูนไล่ลงแนวตั้ง
- หางบอลลูนต้องชี้ไปที่ปาก/ใบหน้า ไม่ชี้หน้าอก แขน หรือพื้นที่ว่าง
- ห้ามบังตา ปาก มือ อาวุธ จุดปะทะ หรือ silhouette สำคัญ
- ถ้าฉากหลังยุ่ง ให้ใส่ balloon backing ชัดเจนและเพิ่มขอบขาว/ดำ

ตำแหน่งมาตรฐาน:
- ผู้พูดซ้าย: บอลลูนบนซ้ายหรือกลางซ้าย หางชี้ลงขวา
- ผู้พูดขวา: บอลลูนบนขวาหรือกลางขวา หางชี้ลงซ้าย
- ตัวละครอยู่ล่างภาพ: บอลลูนอยู่เหนือหัวในพื้นที่ฟ้า/ผนัง
- ฉากต่อสู้: บอลลูนสั้นมาก หรือใช้ SFX แทน ไม่บังทิศทางดาบ

พื้นที่ขาว:
- ใช้สำหรับพักสายตา
- ใช้สำหรับ title card / narration / silence
- ไม่ใช้เป็นที่รวมบทพูดหลักต่อเนื่องหลายช่วง

## 6. Shot Design สำหรับตอน 1 แบบ 50 ช็อต

ตอน 1 ควรแบ่งเป็น 5 ช่วง:

1. ตลาดและมุกลูเมีย: 1-10
2. เรย์ตกจากฟ้า: 11-22
3. อารินเข้าฉากและปัญหาชื่อ: 23-34
4. เงาผู้ไร้โลกบุก: 35-41
5. เรียกดาบ ต่อสู้ ผลข้างเคียง และ cliffhanger: 42-50

กฎ pacing:
- ช่วงคอมเมดี้: ใช้ medium shot และ reaction shot
- ช่วงตื่นตระหนก: ใช้ wide -> medium -> close-up
- ช่วงแอ็กชัน: ใช้ anticipation -> movement -> impact -> result
- ช่วงดราม่า: ใช้ close-up และพื้นที่เงียบ

## 7. Workflow ใหม่ก่อนทำตอนจริง

1. Research Board
   - เก็บ reference เรื่อง lettering, panel flow, action, color script, character sheet

2. Character Model Pack
   - เรย์, อาริน, ลูเมีย อย่างน้อยตัวละ 1 ชีต
   - ตัวละครเสริม/ตัวละครใหม่ที่มีบทบาทต่อเนื่องต้องมี model sheet ก่อนเข้าตอน
   - ต้องมี turnarounds, expressions, props, color swatches

3. Scene Style Sheet
   - ตลาดเจ็ดลม
   - รอยแยกมิติ
   - สะพานกระจก
   - เงาผู้ไร้โลก

4. Color Script
   - กำหนด palette ของแต่ละช่วงอารมณ์
   - กำหนดจุดที่สีเปลี่ยนตามเหตุการณ์

5. Thumbnail + Balloon Pass
   - ร่างช็อต 50 ช็อตแบบหยาบ
   - วางบอลลูนก่อนผลิตภาพจริง
   - ตรวจว่าอ่านบนมือถือได้

6. Production Pass
   - สร้างภาพโดยอิง model pack และ color script
   - ห้ามแก้คาแร็กเตอร์ตามใจภาพ

7. QA Pass
   - ตรวจ anatomy: แขน ขา มือ หน้า
   - ตรวจ continuity: เสื้อ ผม เครื่องประดับ อาวุธ
   - ตรวจ palette: โทนสีไม่แกว่ง
   - ตรวจ lettering: อ่านรู้ว่าใครพูด
   - ตรวจ action continuity: ไม่กระโดดข้ามเหตุและผล

## 8. Prompt Lock สำหรับภาพตอนหน้า

ต้องมีทุกพรอมป์:

```text
Original Korean manhwa/webtoon production art, consistent character model, clean sharp ink line, controlled cel shading, moderate detail, mobile-readable, consistent color script, expressive but on-model faces, no hyper-rendered illustration look.
```

ต้องมี anatomy guard ในช็อตเสี่ยง:

```text
One single character body only, exactly two arms and exactly two legs, no duplicate limbs, no extra fingers, no twisted anatomy, clear readable silhouette, simple action pose.
```

ต้องมี lettering space guard:

```text
Leave clear negative space inside the panel near the speaking character for Thai speech balloon placement; do not place important face, hands, weapon, or action point in that area.
```
