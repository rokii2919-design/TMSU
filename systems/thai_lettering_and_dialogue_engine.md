# Thai Lettering & Dialogue Placement Engine

ระบบสำหรับการลงคำ ใส่ข้อความบทพูด และจัดวางตัวอักษรภาษาไทยในงานมังฮวา / เว็บตูนของ The Myriad Sea Universe

## Core Goals
- ภาษาไทยต้องถูกต้อง อ่านง่าย และเป็นธรรมชาติ
- บทพูดต้องสั้น กระชับ เหมาะกับมังฮวา ไม่ยืดยาวแบบนิยาย
- ตัวอักษรต้องไม่บิดเบี้ยว ไม่ตกหล่น ไม่ซ้อนทับ ไม่ผิดวรรณยุกต์
- Speech bubble ต้องไม่บังหน้า ตัวละคร มือ อาวุธ หรือจุดสำคัญของภาพ
- ขนาดฟอนต์ต้องใหญ่พอสำหรับอ่านบนมือถือ

## Dialogue QA Rules
ก่อนใส่ข้อความลงภาพ ต้องตรวจ:
1. ความถูกต้องของคำ
2. การสะกดและวรรณยุกต์
3. ความเป็นธรรมชาติของบทพูด
4. ความเหมาะสมกับบุคลิกตัวละคร
5. ความยาวของประโยค
6. จังหวะอ่านแบบเว็บตูน

## Manhwa Dialogue Rules
- หนึ่ง bubble ควรมี 1-2 ประโยคสั้น
- หลีกเลี่ยงข้อความแน่นเกินไป
- ใช้คำพูดแบบคนไทยพูดจริง
- ใช้ caption สั้นเฉพาะจุดจำเป็น
- ไม่ใช้ภาษาบรรยายยาวแบบนิยายใน SCVB-M

## Bubble Placement Rules
- Bubble อยู่ในพื้นที่โล่งของภาพก่อนเสมอ
- ห้ามทับใบหน้า ดวงตา มือ อาวุธ หรือเอฟเฟกต์สำคัญ
- Bubble ต้องไหลตามลำดับอ่านบนลงล่าง ซ้ายไปขวาหรือขวาไปซ้ายตาม layout ที่กำหนด
- เว้น safe margin รอบขอบภาพ
- ใช้ tail ชี้ไปยังผู้พูดอย่างชัดเจน

## Font Rules
- ใช้ฟอนต์ไทยอ่านง่าย หนา และชัด
- หลีกเลี่ยงฟอนต์บางเกินไป
- หลีกเลี่ยงฟอนต์ที่ทำให้สระ/วรรณยุกต์แตก
- สำหรับเสียงตะโกน ใช้ตัวหนา ใหญ่ขึ้น แต่ยังอ่านง่าย
- SFX ใช้ตัวใหญ่ มีพลัง แต่ต้องไม่กลืนภาพหลัก

## Character Voice Lock
### Ray
- พูดน้อย
- deadpan / กวนเงียบ
- ประโยคสั้น
- มักพูดเรื่องธรรมดาในสถานการณ์ไม่ธรรมดา

### Park Arin
- จริงจัง
- น้ำเสียงคม
- หลุดเขินหรือหงุดหงิดเมื่อโดน Ray ปั่น
- บทพูดควรมีจังหวะระหว่างความเท่และความน่ารัก

## Pre-render Checklist
- [ ] บทพูดถูกภาษาไทย
- [ ] ไม่มีคำผิด
- [ ] ความยาวเหมาะกับ bubble
- [ ] วาง bubble ไม่บังจุดสำคัญ
- [ ] อ่านลำดับได้ชัด
- [ ] สอดคล้องกับบุคลิกผู้พูด

## Post-render OCR Checklist
หลังสร้างภาพแล้วต้องตรวจ:
- [ ] ตัวอักษรครบ
- [ ] ไม่มีคำเพี้ยน
- [ ] สระและวรรณยุกต์ไม่หลุด
- [ ] ข้อความไม่แตกหรือเบลอ
- [ ] Bubble อ่านง่ายบนมือถือ
