# มหาสมุทรหมื่นภพ ตอนที่ 1 V4

เวอร์ชันนี้ปรับตามฟีดแบ็กล่าสุด:

- แตกช็อตเป็น 36 ช็อต เพื่อให้การเชื่อมฉากละเอียดขึ้น
- เปลี่ยนชื่อตัวเอกจาก GOLF เป็น เรย์
- ปรับบทพูดให้คอมเมดี้ขึ้น เป็นธรรมชาติมากขึ้น และมีจังหวะสนทนายาวขึ้น
- วางคำแบบเว็บตูน/มังฮวาให้อ่านง่ายขึ้น โดยใช้ช่องว่างสีขาวและบอลลูนคำพูดขนาดใหญ่
- ใช้ฟอนต์ Kanit สำหรับคำพูดและคำบรรยายทั้งหมด
- ลดความแน่นของภาพด้วยการปรับโทนหน้าเว็บให้นุ่มลง เพื่อให้อ่านหลายหน้าแล้วไม่ล้าสายตา
