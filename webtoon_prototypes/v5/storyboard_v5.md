# Storyboard V5 — ตอนที่ 1: ผู้ชายที่ตกลงมากลางตลาดเจ็ดลม

## กฎผลิต V5

- จำนวนช็อต: 50 ช็อต
- บอลลูนคำพูดอยู่ในภาพ ใกล้ตัวละครที่พูด ไม่วางบทพูดหลักในพื้นที่ขาว
- ทุกภาพต้องกันพื้นที่ว่างสำหรับบอลลูนไว้ตั้งแต่ขั้นภาพ เช่น ฟ้า ผนัง พื้นหลังด้านข้าง หรือช่องว่างเหนือไหล่
- คำพูดไม่ทับหน้า มือ อาวุธ หรือจุดแอ็กชันหลัก
- ช่วงตกจากฟ้าใช้ช็อตย่อยแบบต่อเนื่อง หลีกเลี่ยง full-body มุมซับซ้อนที่ทำให้แขนขาบิดเบี้ยว
- ช่วงเรียกดาบใช้ close-up เป็นลำดับ: นาฬิกา -> เส้นสุญญะ -> ด้าม -> ใบดาบ -> ท่าพร้อมสู้
- ฉากต่อสู้ใช้จังหวะต่อเนื่อง: เห็นภัย -> ตัวละครตัดสินใจ -> เคลื่อนที่ -> ปะทะ -> ผลลัพธ์ -> ผลข้างเคียง

## Character Lock

### เรย์
- ชายหนุ่มเอเชีย ผมดำ messy undercut ทรงเดิมทุกช็อต
- แว่นกลมบาง กรอบเงิน/ดำ
- เสื้อแจ็กเก็ตดำ tactical streetwear มีซิปและสายรัด
- กางเกงดำ รองเท้าบูตดำ
- นาฬิกาดำที่ข้อมือซ้ายเสมอ
- สีหน้า: สุขุม หน้าตายนิด ๆ กวนเงียบ
- พลัง: ออร่าสุญญะสีม่วงดำ
- อาวุธ: Noctis Null ดาบสีดำด้านเหมือนช่องว่าง

### อาริน
- หญิงสาวผมยาวสีเงินขาว ทรงเดิมทุกช็อต
- เสื้อคลุมนักล่าสีขาวเงินตัดน้ำเงินเข้ม
- ดาบเงิน Selenia มีระฆังจันทร์เล็กที่ปลายด้าม
- สีหน้า: จริงจัง สุขุม แต่มีความกังวลเวลาพลังเรย์ผิดปกติ
- ออร่าแสงจันทร์สีฟ้าเงิน

### ลูเมีย
- เด็กสาวช่างเครื่อง ผมบ็อบน้ำตาลเกาลัด
- แว่นช่างสีทองเหลืองบนหัว
- เสื้อฟ้าอ่อนกับเอี๊ยม/ผ้ากันเปื้อนครีมน้ำตาล
- อุปกรณ์: ถาด ขนมเมฆา ประแจ/ที่คีบ
- สีหน้า: ขี้โวยวาย ตลก สดมาก แต่ใจดี

## Research Notes

- Webtoon ควรวางตัวละครและบทพูดอย่างตั้งใจในแนวตั้ง และใช้ระยะห่างเพื่อคุมจังหวะการอ่าน
- ตอนทำ thumbnail ต้องวางบอลลูนไว้ตั้งแต่แรกเพื่อไม่ให้ทับจุดสำคัญในภาพ
- บทพูดควรแยกเป็นบอลลูนสั้น ๆ แทนยัดข้อความยาวก้อนเดียว
- ฉากแอ็กชันควรแบ่งเป็นช็อตย่อยที่บอกเหตุ ตัดสินใจ เคลื่อนที่ ปะทะ และผลลัพธ์
- ฉากดาบควรใช้เส้นนำสายตาจากท่าทางและแนวดาบ ไม่ใช่ให้ดาบโผล่มาเฉย ๆ
